Complex UI Landing PageThis project is a responsive web page designed to showcase advanced front-end layout techniques by integrating Bootstrap 5 components with custom CSS styling.   FeaturesResponsive Navigation: Includes a collapsible Bootstrap navbar with disabled section links and a functional-styled search form.   Hero Carousel: A dynamic, sliding image carousel featuring captions and call-to-action buttons built using Bootstrap's built-in JavaScript plugins.   Flexbox Gallery: A centered image display section (.section-1) utilizing CSS display: flex with wrap and gap properties for fluid alignment.   Asymmetrical CSS Grid: A complex image mosaic (.section-2) utilizing display: grid configured with a three-column layout (1fr 1fr 1fr). It uses custom .spanrow and .spancol classes to create varied image dimensions.   Component Cards: A responsive card section utilizing Bootstrap's row and column utility classes (row-cols-1 row-cols-md-3) to display grouped content with shadows and buttons.   Responsive Breakpoints: Custom CSS media queries that adjust the padding of the grid layout for desktop (min-width: 992px), tablet, and mobile (max-width: 767px) viewports.   Footer: A styled bottom section containing useful links, a back-to-top action, and contact information routing to ranjith@gmail.com.   Tech StackHTML5: Provides the semantic structure of the application.   CSS3: Custom styling located in style.css to govern the flex and grid behaviors.   Bootstrap 5.0.2: Imported via CDN for base styling, typography, and interactive UI components.   Setup InstructionsClone or download the project files to your local machine.Ensure you have an asserts/ directory in the root folder containing the referenced image assets (e.g., city.jpg, g4.jpg, g5.jpg, g6.jpg, cliff.jpg, hills.jpg, balloon.jpg) to ensure the galleries render correctly.   Open index.html in any modern web browser to view the application. No local server or build step is required.
